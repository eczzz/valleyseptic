Extracted data

  • meta/<slug>.json — per-page title, meta description, OG tags, schema, headings, image list
  • clean/<slug>.json — semantic body HTML with Avada chrome stripped
  • bodies/<slug>.json — raw body HTML between header and footer
  • audit-all.json — single aggregated per-page audit (used by verify-meta.mjs)
  • _aggregate.json — combined asset/font/script inventory across all pages
  • asset-manifest.json — mapping of original WP URLs to localized /images/ paths
  • page-inventory.md — full URL list from the source sitemap
  • schema-diff.json — last schema-comparison run output
  • audit/<slug>.json — individual per-page audits

Verification scripts

  • capture.sh urls.txt — re-fetch every page via monolith + curl into raw/ and monolith/
  • node audit.mjs — extract per-page metadata into audit/ + audit-all.json
  • node sync-metadata.mjs — regenerate src/data/page-metadata.ts from the audit
  • node extract.mjs · node extract-bodies.mjs · node clean-posts.mjs — content extraction pipeline
  • node download-assets.mjs — re-download all images into public/images/
  • node screenshot.mjs — Playwright side-by-side screenshot run
  • node verify-meta.mjs — diff every head/meta field across all 29 pages
  • node verify-schema.mjs — diff JSON-LD @type nodes across all 29 pages
  • node verify-live.mjs — fresh fetch + diff against dist
